# 好玩就好 樂理好想吐

樂理練習小遊戲：音階折返跑、和弦練功房、節拍器。

👉 **https://patty60723.github.io/music-theory-game/**

## 功能

- **音階折返跑**：大調／小調的音階來回跑，可調速度、節拍器、餘音長度、消音練習，每輪結尾可加 1 拍休止。
- **和弦練功房**：三和弦到十三和弦的圖鑑，鋼琴／吉他都能看、能聽；另有小遊戲（看＋聽、純聽力、自己組和弦）。
- **節拍器**：2/4、3/4、4/4、6/8，敲幾下就能算出速度（Tap Tempo），可一鍵套用到折返跑。

## 安裝成 App

- **iPhone／iPad**：用 Safari 開啟 → 分享 → 加入主畫面
- **Android／電腦版 Chrome、Edge**：網頁上會出現「安裝」提示，或從瀏覽器選單安裝

安裝後可離線使用。頁面最下方的「安裝到主畫面」可以隨時叫出安裝提示。

## 更新紀錄

### 上線與安裝
- 建立網站並開啟 GitHub Pages
- **PWA**：可安裝到主畫面、離線可用；有網路時一律抓最新版
- **安裝提示**：Chrome 顯示「安裝」按鈕，iPhone 顯示「分享 → 加入主畫面」教學；按 ✕ 後可從頁尾叫回
- **App 圖示**：深灰底白字「好玩就好♪」，頁首左上角同步使用

### 新功能
- **節拍器分頁**：敲拍子自動算 BPM、拍號、拍子燈、套用到折返跑
- **休止拍**：折返跑每輪結尾休 1 拍，可在設定開關
- **網址記住設定**：分頁、調性、BPM、和弦、節拍器等存在網址，重新整理不跑掉，也能直接分享
- **iPhone 靜音鍵**：開著靜音鍵也有聲音

### 介面調整
- 標題改為「好玩就好 樂理好想吐」，各裝置統一兩行顯示，電腦版字加大
- 和弦鋼琴依類別只畫需要的長度（三、七和弦 2 個八度，九和弦以上 3 個八度）
- 「一起彈／分解」按鈕統一大小與樣式
- 全站圓角統一為 4／8／12／18px＋膠囊形
- 手機版分頁名稱縮短、和弦切換按鈕排成一行
- 電腦版主要內容上下留白加大

## 開發備忘

- 整個網站就是一個 `index.html`（鋼琴音色已內嵌），不需要建置。
- 離線快取在 `sw.js`。**改了圖示或其他快取檔案時，把 `VERSION` 加一**，已安裝的使用者才會更新。
- 圖示放在 `icons/`：`icon.svg` 是原稿，PNG 是從它輸出的各尺寸。
