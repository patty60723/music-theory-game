# 好玩就好 樂理好想吐

> 這是 `cloudflare` 分支，包含受密碼保護的四聲部練唱室，部署至 [Cloudflare 網站](https://music-theory-game-api.awesome61004.workers.dev)。`main` 繼續維護原本的 GitHub Pages。更新這個分支不需要合併回 `main`。自動部署的一次性設定見 [分支部署說明](docs/cloudflare-branch.md)。

樂理練習小遊戲：音階折返跑、和弦練功房、節拍器與調音器。

👉 **https://patty60723.github.io/music-theory-game/**

## 功能

- **音階折返跑**：大調／小調的音階來回跑，可調速度、節拍器、餘音長度、消音練習，每輪結尾可加 1 拍休止。
- **和弦練功房**：三和弦到十三和弦的圖鑑，鋼琴／吉他都能看、能聽；另有小遊戲（看＋聽、純聽力、自己組和弦）。
- **節拍器**：2/4、3/4、4/4、6/8，敲幾下就能算出速度（Tap Tempo），可一鍵套用到折返跑。
- **調音器**：用麥克風聽音高，顯示音名、簡譜（可選 1＝?）和偏差幾 cent；可調 A4 基準音，按「聽鋼琴」聽標準音高。
- **四聲部鋼琴練唱**：依樂譜合成四聲部鋼琴，搭配逐句、逐字動態歌詞與可彈奏鍵盤；每個聲部可獨立靜音、調音量及指定左右聲道。

## 安裝成 App

- **iPhone／iPad**：用 Safari 開啟 → 分享 → 加入主畫面
- **Android／電腦版 Chrome、Edge**：網頁上會出現「安裝」提示，或從瀏覽器選單安裝

安裝後一般樂理工具可離線使用；四聲部練唱需要連線登入。頁面最下方的「安裝到主畫面」可以隨時叫出安裝提示。

## 開發備忘

### 四聲部鋼琴練唱

- 主畫面順序為「KTV 動態歌詞 → 可彈奏鋼琴 → 練唱控制台與聲部混音」。在下方選擇練唱聲部，上方顯示完整句子、正在唱的字詞與下一句。
- 按「播放」直接依譜演奏四聲部，使用同一份樂譜時間控制聲音、琴鍵與歌詞。連音會持續發聲，休止保持安靜；不必再做 MP3 時間對齊。
- 播放鍵已放大。速度使用起始 BPM（40–200），支援 ±1、±5、拖曳與敲拍定速。譜面中的 120／126／132 BPM 速度變化按同一比例保留；目前速度另行顯示，調慢不變調。
- 練唱控制台可開啟節拍器，與樂譜、BPM 同步；第一拍重音、四拍指示燈與獨立節拍音量。暫停、跳轉或關閉時一併停拍。
- 四個聲部可獨立靜音、調音量和指定左／右聲道。練唱聲部即使靜音，仍保留上方歌詞與虛線琴鍵提示，方便自己唱。
- 選擇練唱聲部會把它放左聲道、其餘放右聲道；「左右對調」可反轉並保留方向。整體音量已提高，另有總音量滑桿。歌詞下方以橫向音條呈現音高與長度，只標音名、休止留白；可展開全部歌詞，點選一句跳至該句練唱。
- 鋼琴支援滑鼠按住／放開、多指觸控與電腦鍵盤。`A W S E D F T G Y H U J K O L P ;` 對應 C4–E5 半音階，可切換八度；方向鍵可在琴鍵間移動，Enter／空白鍵可彈奏焦點琴鍵。
- 琴鍵可在歌曲播放時一起彈，不影響播放進度。切換分頁、隱藏頁面或視窗失焦時會收起手動按住的音，避免卡音。
- 音色已內嵌。練唱資料經 Cloudflare Worker 驗證後載入，不放進離線快取。已移除不用的 MP3、舊對齊資料與預覽圖片；四份 PDF 留作分譜閱讀與重建來源。

程式位於 `finale-player.js`、`finale-score.js`、`finale-player.css`，使用 `assets/finale-score.json`。`python scripts/build-finale-score.py` 可從 PDF 音高、節奏與既有歌詞座標資料重建樂譜（需 PyMuPDF），不使用 MP3 對齊時間。詳見 `docs/finale-score.md`。

瀏覽器整合測試：安裝 Playwright 後執行 `node tests/finale-player.test.cjs`，會自動啟動 Worker 測試服務，使用已安裝的 Microsoft Edge；可用 `CATSHARK_PLAYWRIGHT` 指定模組位置。測試包含實際聲道輸出、多鍵／雙指彈奏、變速不變調、動態歌詞、手機版、登入登出與私有資料不進離線快取。

### Cloudflare 部署與密碼

一般樂理工具維持公開；練唱室由同網域 Cloudflare Worker 提供。密碼放在 Worker Secret `PRACTICE_PASSWORD`，Cookie 簽章金鑰放在 `SESSION_SECRET`（至少 32 字元隨機字串）。樂譜與 PDF 存於私有 R2，不進 Git，程式部署也不會重傳；Worker 驗證登入後可共用邊緣快取，減少 R2 讀取。`assets/`、`dist/` 與本機 `.dev.vars` 都排除 Git。完整操作見 [Worker 部署說明](docs/cloudflare-worker.md)。

- 主頁是 `index.html`（鋼琴音色已內嵌），四聲部功能另載入 `finale-player.js`、`finale-score.js` 和 `finale-player.css`。Worker 部署時自動執行 `scripts/build-worker.mjs` 建立明確區分公開／私有資源的輸出。
- 離線快取在 `sw.js`。**改了圖示或其他快取檔案時，把 `VERSION` 加一**，已安裝的使用者才會更新。
- 圖示放在 `icons/`：`icon.svg` 是原稿，PNG 是從它輸出的各尺寸。
